## 登录管理后台

### 访问地址

```
https://your-domain.com/admin/
```

### 默认管理员

首次安装（`php scripts/install.php` 或首次访问自动迁移）会自动播种默认管理员（登录凭据是**邮箱**，不是用户名）：

| 邮箱 | 密码 |
|------|------|
| `admin@example.com` | `admin123` |

在 `https://your-domain.com/login.php` 用邮箱+密码登录，登录后进入 `/admin/` 后台。

> 🚨 **安全警告**：这是公开的默认凭据。**首次登录后必须立即修改密码**。在修改之前，任何用默认凭据登录的人都能接管系统。

### 安全提示

- **立即修改默认密码 admin123**
- 启用双因素认证（2FA）
- 定期更换密码
- 不在公共电脑登录
- 检查登录日志

### 余额管理

**路径：** `/admin/users.php`（用户详情内调整余额）

#### 调整余额

1. 选择用户
2. 输入调整金额（正数增加，负数减少）
3. 填写调整原因
4. 确认提交

#### 余额变动记录

所有余额调整都会记录：

| 字段 | 说明 |
|------|------|
| 用户 ID | 关联用户 |
| 变动金额 | 正/负金额 |
| 调整后余额 | 变动后的余额 |
| 原因 | 调整原因 |
| 操作员 | 执行操作的管理员 |
| 时间 | 操作时间 |

---

### API Key 管理

#### 重置 API Key

1. 进入用户详情
2. 点击「重置 API Key」
3. 新 Key 会显示（仅一次）
4. 通知用户保存

#### 禁用 API Key

临时禁用而不删除：
- 用户无法通过 API 创建订单
- 历史订单不受影响

### 异常订单处理

#### 待支付超时

- 系统自动检测链上交易
- 超过订单有效期（默认 600 秒）自动标记为 expired
- 用户可申请重新激活

#### 支付金额不符

**场景：** 用户转账金额与订单金额不一致

**处理方式：**
1. 联系用户确认
2. 部分支付：创建新订单补足差额
3. 超额支付：记录为余额或退款

#### 重复支付

**场景：** 同一订单收到多笔链上转账

**处理方式：**
1. 第一笔确认订单支付
2. 后续转账记录为用户余额
3. 或原路退回

## 区块链配置

### 支持的链

链配置定义在 `config/config.php` 的 `$chains_config` 数组中（没有独立的后台链管理页面），修改后即刻生效。

#### 配置项

| 字段 | 说明 |
|------|------|
| Chain | 链标识（trc20/bsc/eth 等） |
| 名称 | 显示名称 |
| Chain ID | EVM 链 ID（TRON 为空） |
| USDT 合约 | USDT 代币合约地址 |
| USDC 合约 | USDC 代币合约地址 |
| 精度 | 代币精度（小数位） |
| 最低支付 | 最低支付金额 |
| 状态 | 启用/禁用 |

---

### 添加新链

1. 在 `config/config.php` 的 `$chains_config` 中新增条目（含 `chain_id`、代币合约、`decimals`）
2. 如为 EVM 链且使用派生地址模式，同步更新 `FeeAddressAllocator::isEvmChain()`
3. 小额真实订单验证到账检测

#### 配置示例

```json
{
    "chain": "arbitrum",
    "name": "Arbitrum One",
    "chain_id": 42161,
    "usdt": ["0xfd086bc7cd5c481dcc9c85ebe478a1c0b69fcbb9"],
    "usdc": [
        "0xaf88d065e77c8cc2239327c5edb3a432268e5831",
        "0xff970a61a04b1ca14834a43f5de4533ebddb5cc8"
    ],
    "decimals": 6,
    "min_amount": 1.0,
    "explorer_url": "https://arbiscan.io/tx/",
    "enabled": true
}
```

---

### 节点与浏览器 API

链上交易检测通过区块浏览器 API 完成，端点内置在 `src/Services/CryptoService.php` 中（不存在 `config/rpc.php` / `config/explorer.php` 这类独立配置文件）：

- **EVM 各链**：使用 Etherscan V2 统一 API（按 `chain_id` 区分链）。API Key 通过常量 `ETHERSCAN_API_KEY` 或后台系统设置提供，建议配置以避免公共额度限流。
- **TRC20**：使用 TronScan / TronGrid 公开 API，可在后台「系统设置」中选择 Tron API 提供方。

## 系统维护

### 数据库备份

#### 自动备份

配置定时任务每日备份：

```bash
0 2 * * * mysqldump -u root -p uapi_db > /backup/uapi_$(date +\%Y\%m\%d).sql
```

#### 手动备份

后台没有备份页面，请在服务器上用 `mysqldump` 手动备份：

```bash
mysqldump -u uapi -p --single-transaction uapi_db > uapi_backup_$(date +%Y%m%d).sql
```
