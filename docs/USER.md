## 账户设置

### 基本信息

**路径：** 「设置」→ 「账户信息」

#### 可修改项

- 邮箱地址（需验证）
- 登录密码
- 时区设置
- 语言偏好

#### 修改密码

1. 输入当前密码
2. 输入新密码（至少 8 位）
3. 确认新密码
4. 保存

---

### API 设置

**路径：** 「设置」→ 「API 设置」

#### 查看 API Key

- 显示你的 API 密钥（`sk_live_xxxxx`）
- **仅显示一次**，请妥善保存
- 如丢失需重新生成

#### 生成新密钥

如密钥泄露或丢失：

1. 点击「重置 API Key」
2. 确认操作
3. 复制新密钥
4. 更新你的代码配置

> ⚠️ **警告：** 重置后旧密钥立即失效

#### 域名绑定

绑定 API Key 的使用域名：

1. 点击「添加域名」
2. 输入域名（如 `yoursite.com`）
3. 保存

**说明：**
- 浏览器端调用会验证来源域名
- 服务器到服务器调用可传递 `domain` 参数绕过

---

### 钱包设置

**路径：** 「设置」→ 「钱包设置」

#### 配置收款地址

为每条链配置收款钱包：

1. 选择链（如 TRC20）
2. 输入钱包地址
3. 确认地址无误
4. 保存

**支持的链：**
- TRC20（Tron）
- BSC（Binance Smart Chain）
- Ethereum
- Polygon
- Optimism
- Arbitrum
- Base
- Avalanche

> ⚠️ **重要：** 确保地址正确，转错无法追回

#### 地址验证

建议先小额测试：
1. 创建小额订单（如 1 USDT）
2. 完成支付
3. 确认钱包收到款项

---

### 双因素认证（2FA）

**路径：** 「设置」→ 「安全设置」

#### 启用 2FA

1. 点击「启用双因素认证」
2. 使用认证 App（Google Authenticator / Authy）扫描二维码
3. 输入 6 位验证码
4. 保存备份码（重要！）

#### 登录时使用

启用后登录需要：
1. 输入密码
2. 输入 App 中的 6 位动态码

#### 丢失设备

如手机丢失：
1. 使用备份码登录
2. 或联系客服协助

## 收款功能

### 创建订单（API）

通过 API 创建订单，适合集成到网站/应用：

```bash
curl -X POST https://your-domain.com/api/v1/order/create.php \
  -H "X-API-KEY: sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 100.00,
    "chain": "trc20",
    "merchant_order_id": "ORDER-001"
  }'
```

详见 [API 文档](./docs/API.md)

---

### 支付链接

**路径：** 「收款」→ 「支付链接」

#### 创建支付链接

无需编程，快速生成收款链接：

1. 点击「创建链接」
2. 填写：
   - 金额（固定或用户输入）
   - 标题/描述
   - 支付链
   - 过期时间（可选）
3. 生成链接
4. 复制发送给客户

#### 使用场景

- 自由职业者收款
- 二手交易收款
- 捐赠链接
- 活动报名费

#### 示例链接

```
https://your-domain.com/pay_link.php?id=abc123
```

### 收款码

**路径：** 「收款」→ 「收款码」

#### 生成收款码

1. 点击「生成收款码」

3. 输入金额（可选，留空由付款方输入）
4. 下载二维码图片

#### 使用场景

- 实体店收款
- 网站嵌入
- 社交媒体收款
- 活动现场

#### 自定义样式

- 添加 Logo
- 更改颜色
- 添加文字说明

### 在线商店

**路径：** 「商店」→ 「管理商店」

#### 创建商店

1. 点击「创建商店」
2. 填写商店信息：
   - 商店名称
   - 描述
   - Logo
3. 保存

#### 添加商品

1. 进入商店
2. 点击「添加商品」
3. 填写：
   - 商品名称
   - 价格
   - 描述
   - 图片
   - 库存（可选）
4. 保存

#### 商店页面

每个商店有独立页面：

```
https://your-domain.com/store.php?id=1
```

客户可直接下单支付。

## 通知设置

### 通知渠道

**路径：** 「设置」→ 「通知设置」

#### 站内通知

- 默认开启
- 控制台右上角铃铛图标
- 实时接收

#### 邮件通知

配置 SMTP 发送通知：

1. 开启邮件通知
2. 配置 SMTP：
   - SMTP 主机
   - 端口
   - 用户名
   - 密码
   - 发件人邮箱
3. 测试发送
4. 保存

**通知类型：**
- 订单支付成功
- 订单取消
- 账户变动
- 系统公告

#### Telegram 通知

通过 Telegram Bot 接收通知：

1. 开启 Telegram 通知
2. 输入 Bot Token
3. 输入 Chat ID
4. 测试发送
5. 保存

**获取 Chat ID：**
1. 搜索 [@userinfobot](https://t.me/userinfobot)
2. 发送 `/start`
3. 获取 ID

---

### 通知策略

自定义哪些事件触发通知：

| 事件 | 站内 | 邮件 | Telegram |
|------|------|------|----------|
| 订单支付 | ✅ | ✅ | ✅ |
| 订单取消 | ✅ | ❌ | ❌ |
| 余额变动 | ✅ | ✅ | ❌ |
| 系统公告 | ✅ | ✅ | ✅ |

## 常见问题

### 账户相关

#### Q: 如何修改注册邮箱？

A: 「设置」→ 「账户信息」→ 修改邮箱 → 验证新邮箱

#### Q: 忘记密码怎么办？

A: 登录页点击「忘记密码」→ 输入邮箱 → 查收重置链接

#### Q: 如何注销账户？

A: 提交工单申请注销，账户需无余额和进行中的订单

---

### 支付相关

#### Q: 客户反馈无法支付？

A: 检查：
1. 订单是否过期（默认 10 分钟有效期，以创建订单返回的 `expire_in` 为准）
2. 支付链是否正确
3. 钱包是否有足够余额和手续费

#### Q: 支付后订单未更新？

A: 
1. 等待 1-3 分钟系统确认
2. 检查链上交易是否成功
3. 如超过 10 分钟未更新，提交工单提供 TXID

#### Q: 用户转错账怎么办？

A: 
1. 记录交易哈希（TXID）
2. 提交工单
3. 客服协助处理

---

### 提现相关

#### Q: 如何提现余额？

A: 
1. 「财务」→ 「提现」
2. 输入提现地址和金额
3. 确认手续费
4. 提交申请

#### Q: 提现多久到账？

A: 
- 自动审核：1-10 分钟
- 人工审核：1-24 小时
- 链上确认：1-30 分钟（取决于网络）
